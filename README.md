## 🖥️ What this app does

pi-session-summary is a pi extension that keeps your session name short and clear.

It uses an LLM to write a one-line summary of the current session. That summary becomes the session name, so you can see what a session is about at a glance.

This helps you:

- spot the right session fast
- keep long lists easier to scan
- avoid manual renaming
- stay organized across many sessions

## ⚙️ How it works

pi-session-summary watches the session and creates a one-line summary from the current context.

That summary is then used as the session name.

This gives each session a simple label that matches the work inside it.

Example session names might look like:

- Weekly planning
- Bug fix for login flow
- Drafting support reply
- Review notes for release
- Set up new account flow

## 🛠️ Troubleshooting

If the session name does not update:

- Check that the extension is enabled

- Refresh pi and try again
- Restart the app if it stops responding

If Windows blocks the app:

- Select Properties
- Check for an Unblock option
- Apply the change if you see it
- Try opening the file again

If the summary looks wrong:

- Start a new session with clearer context
- Use short, direct prompts
- Give the session a few messages before checking the name

## 🔒 Privacy and data use

pi-session-summary uses session text to create a one-line name.

It is built to help with naming and session flow, not with long-term note keeping.

If your setup sends session content to an LLM, use it in a way that fits your privacy needs and your team rules.
